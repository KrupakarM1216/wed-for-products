# wed-for-products
A static product catalog starter page for "Wed for Products". This project contains a minimal landing page and is configured to deploy on Vercel.

## Live demo
https://wed-for-products.vercel.app/

## How to deploy / update
1. Push changes to `main` (this repo is already connected to Vercel).
2. Vercel will auto-deploy on each push to `main`.
3. Open a pull request to preview changes before merging to `main`.

## How to customize
- Edit `index.html` to change content, add products, or link to a backend / CMS.
- Add CSS and JS files and reference them from `index.html`.
- Add images to `public/` (or any folder) and reference with relative paths.
- For dynamic data, connect to an API or use a headless CMS.
